Quando a ideia não envia, a tela mostra o motivo ao lado do campo. Procure a
mensagem abaixo.

## Problemas comuns

| O que acontece | O que fazer |
| --- | --- |
| **Selecione a data primeiro**, no campo de formato | Escolha a **Data Sugerida para Publicação**. Os formatos aparecem depois. |
| **O formato "…" não é permitido para…**, com os dias disponíveis | O seu calendário não tem esse formato nesse dia da semana. Escolha um dos dias listados ou outro formato. |
| **Limite mensal atingido**, ao lado do formato | O plano já usou todos os posts desse formato no mês. Escolha outro formato ou uma data no mês seguinte. |
| **Nenhuma rede incluída no plano contratado** | O seu plano não tem rede para essa ideia. Veja [Assinar ou trocar de plano](/conta/assinar-ou-trocar-de-plano). |
| **Não há disponibilidade para a data selecionada** | As sugestões devem ser feitas para o próximo mês. Mude a data. |
| O arquivo não sobe | O limite é 50 MB por arquivo. Comprima o vídeo ou envie em partes. |

Ainda não conseguiu? Fale com o [suporte](/ajuda/falar-com-o-suporte).
